# Design-system skill registry

Installed from https://github.com/bergside/awesome-design-skills (MIT, typeui.sh) on 2026-09-24.
Each entry under `registry/<slug>/` has a `SKILL.md` (agent instructions: brand, typography scale,
palette, spacing, component families, WCAG 2.2 AA rules, do/don't, quality gates) and a `DESIGN.md`
(human rationale). To update: re-clone the repo and copy its `skills/` over `registry/`.

## How to use

1. Read the brief. Decide the direction from the table below (or ask when several fit).
   Defaults for this workspace: **enterprise** / **corporate** / **professional** for internal
   UnifyApps dashboards and product UI, **minimal** / **clean** / **editorial** for content-heavy
   pages, **shadcn** when the code app already uses shadcn/ui.
2. Read `registry/<slug>/SKILL.md` in full and follow it as the design system for that build.
   Read `DESIGN.md` only if the rationale matters for a decision.
3. Combine with `taste-skill` (anti-slop layout/typography judgement) and the UnifyApps brand
   tokens from `unifyapps-document-theme`; brand tokens override a registry palette when the
   deliverable is customer-facing UnifyApps material.
4. Check the skill's quality gates before calling the UI done.
